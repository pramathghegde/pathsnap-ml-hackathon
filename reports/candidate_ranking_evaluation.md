## 1. Executive Summary

In map-matching and GPS trajectory reconstruction, classifying candidate road segments as binary positives/negatives is merely an intermediate surrogate objective. The actual operational goal of the observation-level emission model is **Candidate Ranking**: for every GPS observation, the model must rank all candidate road segments generated by spatial indexing and select the single most probable arc (the **Top-1** choice).

Prior benchmarks primarily measured candidate-level metrics (Accuracy ~94.5%, Macro F1 ~0.868, Log Loss ~0.132). These candidate-level metrics mask critical real-world map-matching behaviors:
1. Candidate accuracy is artificially inflated because negative candidate segments heavily outnumber positive segments (approx. 7:1 ratio).
2. A model can achieve 94.5% candidate classification accuracy while simultaneously picking the *wrong* candidate segment as its Top-1 prediction for 20% of eligible observations.
3. Candidate generation recall misses (observations where no candidate road segment matches ground truth) are completely ignored by candidate-level classification accuracy.

To resolve this gap, we implemented a vectorized, mathematically rigorous **Observation-Level Top-1 Ranking Evaluation Engine** in `src/models/evaluate.py`, verified it against 12 comprehensive unit tests in `tests/test_ranking_evaluate.py`, and benchmarked the baseline `HistGradientBoostingClassifier` across all 80 training trips (5 folds, 208,244 GPS observations, 1,565,762 candidate rows).

## 2. Mathematical Formulation & Metrics

For a trip consisting of $N$ GPS observations $\{o_1, o_2, \dots, o_N\}$, candidate generation produces a variable set of candidate road arcs $C(o_i) = \{a_{i,1}, a_{i,2}, \dots, a_{i,K_i}\}$ for each observation $o_i$. Each candidate arc $a_{i,j}$ has a ground-truth label $y_{i,j} \in \{0, 1\}$ and a model predicted probability $\hat{p}_{i,j} \in [0, 1]$.

### 2.1 Observation Eligibility & Candidate Misses
An observation $o_i$ is **eligible** if and only if at least one candidate road segment is the true ground-truth match:
$$\text{Eligible}(o_i) \iff \sum_{j=1}^{K_i} y_{i,j} \ge 1$$
If $\sum_{j=1}^{K_i} y_{i,j} = 0$, candidate generation failed to retrieve the true road segment. This observation is a **Candidate Generation Miss**. No ranking model can possibly recover the true arc from this candidate set.

- **Total Observations ($N_{\text{total}}$):** $\sum_{i} 1 = 208,244$
- **Eligible Observations ($N_{\text{eligible}}$):** $\sum_{i} \mathbb{I}(\text{Eligible}(o_i)) = 183,062$
- **Candidate Misses ($N_{\text{miss}}$):** $N_{\text{total}} - N_{\text{eligible}} = 25,182$ (12.09%)
- **Candidate Generation Recall:**
  $$\text{Recall}_{\text{cand}} = \frac{N_{\text{eligible}}}{N_{\text{total}}} = \frac{183,062}{208,244} = 87.907\%$$

### 2.2 Deterministic Top-1 Selection
For each observation $o_i$, the model ranks candidates descending by $\hat{p}_{i,j}$. In case of identical predicted probabilities (e.g., ties), we apply a deterministic tie-breaker preferring the candidate segment with the smallest perpendicular distance:
$$a_{i}^* = \arg\max_{a_{i,j} \in C(o_i)} \left( \hat{p}_{i,j}, \; -\text{perp\_dist}_{i,j} \right)$$

The observation is scored as a **Correct Top-1 Selection** if and only if $y(a_i^*) = 1$:
$$\text{Correct}(o_i) \iff y(a_i^*) = 1$$

### 2.3 The Two Essential Ranking Accuracies
We distinguish between:
1. **Eligible Top-1 Accuracy:** The accuracy of the model when the true road segment was present in the candidate set. This isolates the model's discriminative ranking performance from candidate generation quality:
   $$\text{Acc}_{\text{eligible}} = \frac{\sum_{o_i \in \text{Eligible}} \mathbb{I}(\text{Correct}(o_i))}{N_{\text{eligible}}}$$

2. **Overall Top-1 Accuracy:** The end-to-end accuracy across all GPS observations. Any candidate generation miss is strictly counted as an incorrect observation prediction ($0$ score):
   $$\text{Acc}_{\text{overall}} = \frac{\sum_{o_i} \mathbb{I}(\text{Correct}(o_i))}{N_{\text{total}}}$$

### 2.4 Fundamental Identity
Because an observation cannot be correct if it is a candidate miss, the two metrics satisfy the exact mathematical identity:
$$\text{Acc}_{\text{overall}} = \text{Acc}_{\text{eligible}} \times \text{Recall}_{\text{cand}}$$

## 4. Analytical Insights & Comparison

### 4.1 Candidate-Level vs. Observation-Level Discrepancy
Comparing candidate classification accuracy to observation ranking accuracy reveals why candidate accuracy alone is misleading:

| Metric Type | Metric Name | HistGradientBoosting Score | Interpretation |
|:---|:---|:---:|:---|
| Candidate-Level | Accuracy | **94.51%** | 94.5% of individual candidates correctly labeled 0 or 1. Heavily biased by 7:1 negative majority. |
| Candidate-Level | Macro F1 | **0.8679** | Balanced harmonic mean across positive and negative candidates. |
| Observation-Level | Eligible Top-1 | **80.10%** | When ground-truth is in candidate set, model chooses it as #1 in **80.1%** of observations. |
| Observation-Level | Overall Top-1 | **71.99%** | Real-world trajectory accuracy. Degraded by the 12.09% candidate generation miss rate. |

### 4.2 Impact of Spatial Candidate Retrieval (Fold 3 Analysis)
In Fold 3, candidate generation recall dropped to **70.48%** (17,315 misses out of 58,652 observations), causing Overall Top-1 Accuracy to fall to **52.79%**, despite the model maintaining an Eligible Top-1 Accuracy of **74.90%**. This confirms that model performance in map-matching is strictly bounded by spatial candidate generation recall.

### 4.3 Computational Efficiency
Inference latency is approximately **0.013 ms per observation** (over 76,000 observations per second on a single CPU core). This satisfies the requirements for real-time map matching in the FastAPI backend.
