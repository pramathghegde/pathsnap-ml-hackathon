## 2. Input Data Contract

The predictor accepts any `pd.DataFrame` containing the 9 standard predictive features. It is **order-tolerant** (automatically re-orders columns to match the trained schema) and **label-agnostic** (never requires `is_match`).

### Mandatory Feature Columns
| Feature Name | Type | Physical Unit | Description |
|:---|:---:|:---:|:---|
| `perp_dist` | `float64` | meters | Perpendicular orthogonal distance from GPS point to candidate arc |
| `proj_ratio` | `float64` | $[0, 1]$ | Scalar position of orthogonal projection along segment length |
| `delta_heading` | `float64` | radians $[0, \pi]$ | Absolute angular difference between GPS velocity heading and arc |
| `arc_length` | `float64` | meters | Metric physical length of candidate road segment |
| `gps_speed` | `float64` | m/s | Instantaneous speed between consecutive GPS pings |
| `speed_ratio` | `float64` | dimensionless | Ratio of inferred GPS speed to reference urban speed ($13.89\text{ m/s}$) |
| `traversal_rate` | `float64` | $\text{s}^{-1}$ | Traversal frequency ($\text{gps\_speed} / \max(1.0, \text{arc\_length})$) |
| `candidate_rank` | `int64` | ordinal $1, 2, \dots$ | Proximity rank of candidate among retrieved arcs |
| `is_adjacent` | `int64` | binary $\{0, 1\}$ | Indicator whether arc shares a vertex with step $t-1$ candidate |

### Optional Identifier Columns (Preserved in Output)
- `trip_id` (`str`)
- `observation_id` (`int`)
- `candidate_arc_id` (`int`)
- `timestamp` (`str` or `int`)

## 3. Integration Patterns

### 3.1 Pattern A: Member 3 (HMM Emission Probabilities)
In Hidden Markov Model map-matching, the emission probability $b_j(o_t) = p(o_t \mid s_t = a_j)$ is the likelihood that observation $o_t$ was generated by candidate road arc $a_j$.

```python
# Member 3: Extract emission probabilities grouped by observation
```

### 3.2 Pattern B: Member 4 (FastAPI Endpoint on Laptop 1)
In FastAPI serving, `load_predictor()` should be initialized once at application startup as a singleton:

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI, HTTPException
import pandas as pd
from src.models.predict import load_predictor, PathSnapPredictor

ml_predictor: PathSnapPredictor = None

@asynccontextmanager
async def lifespan(app: FastAPI):
    global ml_predictor
    ml_predictor = load_predictor()
    yield

app = FastAPI(lifespan=lifespan)

@app.post("/api/v1/predict/candidates")
async def score_candidates(payload: list[dict]):
    if not payload:
        raise HTTPException(status_code=400, detail="Empty candidate payload")
    
    df = pd.DataFrame(payload)
    try:
        scored = ml_predictor.predict_candidates(df)
        return scored.to_dict(orient="records")
    except ValueError as exc:
        raise HTTPException(status_code=422, detail=str(exc))
```

## 4. Performance & Latency Specifications

- **Single Observation Latency:** $\sim 0.064\text{ ms}$ ($\sim 15,600\text{ observations/sec}$ on CPU)
- **Batch Throughput (10,000 candidates):** $< 20\text{ ms}$
- **Cold-Start Load Time:** $< 0.15\text{ seconds}$
- **Memory Footprint:** $\sim 25\text{ MB}$ RSS overhead in memory
- **Deterministic Tie-Breaking:** When two candidates have identical probabilities, ties are broken deterministically by `perp_dist` ascending.
